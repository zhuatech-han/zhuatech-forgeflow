## 建立岗位与档案

管理员在账号管理中创建计划员、仓管、操作员和独立质检员，选择部门、角色并设置独立强密码。账号停用立即撤销已有会话；重设密码后旧会话失效。角色权限与数据范围分别控制：ALL 为所有部门，DEPARTMENT 为本部门，ASSIGNED 为本部门且工序派给该账号的工单。成本不是普通查看权限。账号密码只能重设，不可查询。保留至少一个启用的全局管理员。

菜单可改中英文名称、顺序、所需权限和启停；隐藏菜单不会取消接口权限，也不会授权原本没有的操作。内建权限仅改名称，不能凭新增代码产生未实现的功能。部门有业务引用时不能删除。业务字典 `variance_reason` 控制送检时的材料偏差原因，可增加、改名、停用；历史偏差说明保持原文本。参数可设组织名、时区及币种；有任何工单或库存流水后禁止改变币种。

物料与成品都需要编码、名称、类型、基本单位和部门。原材料数量最多六位小数，例如 0.012390 kg；成品实际收发和产量按整数件。使用统一基本单位，没有采购单位换算。类型、单位、部门保存后不能改动；名称规格可改，历史快照保留。库存收货输入数量、单位成本和真实凭证号；盘点输入实盘数量及原因，若账面数量已变动则拒绝旧盘点。成品发出不生成销售订单或应收账款。材料库存出库只通过工单领料。

物料批量导入按钮接收最多500条 JSON 数组，任一无效整批回滚。示例结构（自行换成可用部门、独立编码）：

```json
[{"code":"MAT-01","name":"钢材","kind":"MATERIAL","unit":"kg","departmentId":1,"enabled":true,"reorderLevel":"2.000000","specification":"规格说明"}]
```

## BOM 与工艺版本

先建工位及标准小时费率，再选择成品创建 BOM 草稿。材料行按每一件成品填写用量，工序按列表顺序执行，可复用工位但名称应明确。最多50种材料、50道工序，仅单层 BOM。费率在 BOM 保存时从工位固化，更改工位后不会重算已有 BOM；新版本草稿重新取当前费率。

启用后冻结，需改变配方或工艺时新建版本；归档阻止新计划和下达，不改变已经下达工单。未引用草稿可编辑删除，已启用版本保留。所有物料、工位和成品须同一部门并启用。

## 计划、领料与派工

计划员选择启用 BOM、计划整数件数、交期，填写可选外部单号与备注。下达将每件用量乘计划数量，固化材料标准用量／可领上限及顺序工艺，后续主数据变动不会重写快照。草稿可编辑或取消，下达后不能改计划数量与工艺。

为每道工序选择本部门启用且具有报工权限的账号；已经有有效报工或已完工的工序不能直接换人。仓管按材料逐项领料，不能超过可领上限，也不能超过可用库存。确需多领时，由计划员调整可领量并填写原因，标准用量不变。退料必须选择本工单该材料的原领料凭证，累计不能超过原量，按原成本恢复库存；不是按当前材料均价倒算。全部工序派工、各材料均有正净领数量后才能开工；允许分批领料，不假设系统已预约库存。

开工前取消已下达工单必须退回全部领料。生产中不能强行取消或清零；在制品停产、拆解及报废处置单不在本版范围，需要按业务规则扩展。

## 工序报工、完工与返工

操作员只见派给自己的工单，只能登记本人派工的工序。首道转入量等于计划件数，后道转入量等于已完工前道的净良品。每次报工录入良品、报废、实际小时及凭证号；数量整数、工时三位小数。良品加报废累计不能超过转入量。即使前道全报废，后道仍须登记完工，转入量为0。

工序完工要求良品加报废等于转入量。未交代数量必须继续报工或核查。报工错误由计划员填写原因冲销，原记录保留，工序重开；后道有有效报工或已完工后，不能冲销前道。可以冲销末道错误报工再补登，成本以未冲销报工为准。

全部工序完工后计划员送检。如果净用料不等于标准，必须选择启用偏差原因并填写说明，不能隐式假设超耗已被批准。

本单任何曾报工的人不能做终检，包括冲销记录中的人。质检人员填写检验通过与否、最终合格件数和检查记录。通过时合格数量不能超过末道良品；不通过时合格数须0，保留失败记录并重开末道工序。返工可登记0产出、正工时，原数量不重复增加，完成后再次送检。该流程不是复杂返工路线或跨工单返工。

## 入库、成本与报表

终检通过后仓管录入入库凭证号结单。净材料成本为原领料成本减原单退料价值；人工为各次有效工时乘 BOM 固化费率，两位金额逐次舍入。最终合格数大于0时，整单成本计入这些成品库存价值；过程损耗随整单成本分摊。合格数为0时无成品入库，整单金额记为零良品损失。已完结记录不可重新报工、退材料或入库。凭证号不代表外部财务已对账。

库存使用移动平均价值出库，最后一份取走全部剩余价值；退料最后一份恢复剩余原成本尾差。币种只支持两位小数，单位成本及费率最多四位，不含税额、折旧、制造间接费用、工资结算、批次追溯或财务凭证。

统计按配置时区的实际入库／结单日期筛选，只统计 COMPLETE 工单。计划数减最终合格数为整单损耗件数，不把各道报废重复相加。成本权限单独控制网页、接口及 CSV 字段。列表搜索和分页不影响 CSV 的日期范围。工单打印保留业务快照和履历，界面按钮不打印。

界面右上角切换中文／English。服务器仍以统一字段、同样权限和精度运行；记录名称不会自动翻译。对外部署、备份与授权见部署说明和 LICENSE。
